# 常见问题

## 支持的 OBS 版本

| 平台 | 支持的 OBS 版本 |
| --- | --- |
| Windows 10 / 11 x64 | OBS Studio **29.1 及以上**（已在 29.1.3 / 30.2.3 / 31.1.2 / 32.2.2 / 33.0.x 上验证） |
| macOS 12+ | 见 [README](../README.md) 的兼容性说明 |
| Linux（.deb） | 与安装时发行版仓库（PPA）里的 OBS 版本一致及更新版本 |
| Flatpak | 与 `com.obsproject.Studio` stable runtime 的 OBS 版本匹配 |

旧版（OBS 28 及以下）不保证可用。插件载入失败时 OBS 日志会写 `Module '...obs-kaibo.dll' not loaded`。

## 面板在哪里？

OBS 菜单 **停靠窗口（Docks）→ Kaibo 开播**，或 **工具 → Kaibo 开播**。如果两处都没有，说明插件没有加载，请看下面的「查看日志」。

## 想把面板放到最右侧、占满整栏

OBS 的停靠区默认会被下方的混音器 / 控制项占去右下角，所以右侧的停靠面板无法「顶天立地」。有两种做法：

1. 打开 OBS 菜单 **停靠窗口（Docks）→ 全高度停靠窗口**（OBS 33 起提供），右侧整列就都归停靠面板；
2. 或者点 Kaibo 的 **工具 → 将面板放到右侧全高**：Kaibo 会把面板移回右侧，并在 OBS 支持时自动打开上面的「全高度停靠窗口」。

面板本身没有尺寸限制，可以自由拖动、缩放，最窄 280px。如果拖动后行为异常，可用 **工具 → 将面板放到右侧全高** 复位。

**全新安装的 OBS 首次启动时**，OBS 会先弹出首次设置向导，Kaibo 面板这时可能以浮动窗口出现；关掉向导后点 **工具 → 将面板放到右侧全高** 即可停靠到右侧，之后 OBS 会记住布局。

## 面板 / OBS 有点卡

1.1.0 起面板只在需要时重绘：输入标题、后台刷新、面板隐藏时不会反复重建界面。如果仍然觉得卡：

- 关闭 OBS 的「预览」或减少同时打开的其他停靠面板/浏览器源；
- 打开 **帮助 → 日志文件 → 查看当前日志**，搜索 `[obs-kaibo]`，把相关行附到 Issue；
- OBS 自身的性能问题（渲染/编码占用过高）也会表现为界面卡顿，可看 OBS 状态栏的 CPU / 丢帧统计。

## 二维码扫不出来 / 一直显示「正在获取二维码」


- 确认电脑能打开 <https://passport.bilibili.com>。
- 二维码 3 分钟后过期，点一下二维码即可刷新。
- 公司或学校网络可能拦截 B 站接口，换个网络试试。

## 开播失败

Kaibo 会显示 B 站返回的原文和错误码，常见情况：

| 提示 | 原因与处理 |
| --- | --- |
| 需要人脸认证 | B 站要求开播前完成人脸认证（部分账号/分区是每场都要）。面板里会显示认证二维码：用哔哩哔哩 App 扫码完成认证，然后点「已完成认证，重试开播」，Kaibo 会自己等几秒并重试，不用反复扫码。如果始终过不去，请确认扫码用的是同一个账号；若官方直播姬在同一台电脑、同一分区也每次都要求，那是 B 站的政策，插件无法跳过 |
| 分区显示「需申请」 | 该分区需要先在 B 站申请权限，换一个分区或去直播中心申请 |
| 登录已失效 | 重新扫码登录即可；退出登录不会影响直播间 |
| 网络错误 | Kaibo 会自动重试；横幅里也有「重试」按钮 |

## 「直播间已开启 · OBS 未推流」

直播间开着，但 OBS 没在推流，观众看到的是黑屏或「主播暂时离开」。点横幅里的「开始推流」，或「关闭直播间」。

## 推流断了

网络或服务器问题导致推流中断时，Kaibo **不会**关闭直播间，横幅里点「重新推流」即可恢复。只有你自己在 OBS 里点「停止直播」时，才会按设置自动关闭直播间。

## 我同时在别的平台直播

打开 **设置 → 关播后恢复原来的推流设置**。Kaibo 开播时会备份原来的推流设置，关播后改回去。如果开播时 OBS 已经在推流，Kaibo 只开启直播间、不改动推流设置。

## 安装后 OBS 里有两个 B 站菜单

那是旧版「BILIBILI Stream for OBS」。Windows 安装程序里勾选「移除旧版插件」，或手动删除 `C:\ProgramData\obs-studio\plugins\bilibili-stream-for-obs`。

## 查看日志

OBS 菜单 **帮助 → 日志文件 → 查看当前日志**，搜索 `[obs-kaibo]`。日志里不会包含 Cookie 或推流码，可以放心附在 Issue 里。

## 反馈问题

到 <https://github.com/PZW152/obs-kaibo/issues> 提交，请附上：OBS 版本、系统版本、Kaibo 版本（设置 → 关于）和相关日志。
